# X-Lang Labs 研究区

Labs 用于 GC、通用 Replay、ZKP、硬实时认证、GPU/eBPF 高风险后端、自动修复和其他尚未满足稳定证据的能力。Labs 默认关闭，稳定项目不得依赖其实现或隐式启用其权限。

每个研究主题必须有独立 Charter、假设、原型边界、预算、基准、威胁模型、数据政策、退出条件和 Go/No-Go ADR。研究失败应保留实验报告，不得通过改写指标宣称成功。
