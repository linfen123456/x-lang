# x-style 样式与可访问性契约

## 目标与非目标

以独立 DSL/生态吸收 CSS 的选择器、级联、布局、响应式、主题、动画和无障碍能力，不改变 X-Lang 核心求值语义。目标是可预测的样式 IR 和多后端降级，不复制 CSS 历史兼容行为的全部细节。

## 核心契约

选择器匹配、级联优先级、继承、变量解析和布局计算必须有确定顺序；Flex/Grid 和响应式断点必须记录可用空间、溢出和降级行为。动画必须可取消、遵守 reduced-motion，并在服务端渲染时有静态回退。

## 正反例

正例：主题变量缺失时使用显式 fallback，并产生 lint 提示。反例：样式 DSL 隐式修改业务状态或绕过组件权限。

## 边界、安全与性能

样式不能执行任意代码或发起未声明网络请求。隔离策略（Shadow DOM/命名空间/组件边界）和 SSR 输出必须明确。基准记录样式匹配、布局、重排次数和首屏 P95；截图黄金不是跨平台绝对像素承诺。

## 测试与回滚

`tests/style` 使用 CSS/WPT 对照、选择器/级联单测、截图差分、响应式矩阵和 WCAG 自动+人工审查。规则变化通过版本化样式 IR、迁移工具和旧渲染器回滚；不修改核心编译语义。

## P3–P6 入口

- P3：Selector/Cascade/变量/主题与静态 IR。
- P4：Flex/Grid、响应式、SSR 和布局诊断。
- P5：动画、跨平台渲染、组件隔离、WCAG 工具链。
- P6：实验性 GPU 渲染、设计系统推导和多端统一研究。
