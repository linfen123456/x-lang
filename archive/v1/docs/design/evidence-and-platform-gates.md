# 阶段证据、黄金项目与目标晋级

> 状态：Proposed｜日期：2026-09-29｜责任：符合性/安全/性能 Owners；是设计与验收草案，不是已有测试结果。

## 1. 可复现对照

三个贯穿阶段的黄金项目：CLI 工具（解析、文件和失败恢复）、带 API 的服务端（并发、超时和持久化边界）、业务 UI（表单、列表、离线状态）。先冻结需求、数据集、环境、目标版本、对照实现与统计程序，才收集指标。对照现有语言/宿主实现时要求功能等价，记录未完成或不支持，不选择性报告胜出子集。

指标覆盖功能/安全正确率、可读性与维护任务时间、全量/增量编译时间、包体、峰值内存、吞吐、P50/P95/P99、崩溃/恢复、无障碍及平台差异；重复运行，公开原始数据、工具链版本、硬件与置信区间/波动范围。无基线时只报告绝对值，不宣称“最快/最安全/解决全部痛点”。

## 2. 阶段化证据门禁

| 阶段 | 至少交付 | 停止/回退 |
|---|---|---|
| D0 | 词法、类型、所有权、错误、模块、包图 RFC 冲突表；正反语料设计；Owner 与评审记录 | Proposed 决策不得写成已批准语义；不锁工具链前不开发布承诺 |
| P0 | 单宿主 Hello World、三包图/Action DAG/LLVM 链接、ABI 探针、自动阻断语料和 CI | 任一核心门禁失败不进 P1；不得把单包 M3 视为 P0 完成 |
| P1–P2 | 借用/Drop/Result/FFI 正反例、优化差分、安全审计、稳定诊断和基准 | 不完整语义明确拒绝，不静默接受；禁以优化改变可观察结果 |
| P3 | Web/WASI、XUI、AI SDK 隔离原型，组件/宿主接口与故障注入 | 原型失败回退宿主桥，UI/AI 不成为核心依赖 |
| P4 | Web 黄金产品跨浏览器、无障碍、离线和安全门禁 | 未通过则仅实验支持，不宣称稳定 Web 平台 |
| P5+ | 每个桌面、移动、微信目标单独真机/发布/恢复报告 | 失败仅阻断该宿主等级，不倒逼修改稳定核心 |

每阶段公开目标矩阵、已知限制、性能基线、安全审查、工件、复现命令、迁移/回滚策略和 Owner 签名。报告状态分“计划、原型、已实现、稳定”；缺失证据不得晋级。

## 3. 团队与交付依赖

按 15–30 人并行团队估算：语言/编译器维护唯一语义主线；符合性/安全与构建生态并行提供独立门禁；Web/WASI、XUI、AI/开发体验仅消费明确的公开接口。平台团队在 UI IR/能力契约形成后并行，桌面/移动/微信单独发布。人数为资源假设，不是日程承诺；容量不足时首先保持核心及门禁，延后平台并行而非放宽安全或正确性条件。
