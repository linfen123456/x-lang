# X-Lang

X-Lang 是一个处于设计与工程规划阶段的现代编程语言项目，目标是为系统编程、服务端、命令行工具和跨平台应用提供安全、清晰、可诊断的语言与工具链。

项目计划使用 Rust 实现初始编译器，以 LLVM 作为首个原生代码生成后端，并采用所有权、借用与 RAII 作为核心资源安全模型。

> 当前仓库是 **X-Lang 的架构与文档基线**，尚未包含可构建的编译器代码。现有文档中的目录树和模块均为目标设计，不代表已经实现。

## 设计基线

- 初始编译器使用 Rust 实现。
- 首个稳定原生后端使用 LLVM，并通过后端接口隔离 LLVM 类型。
- 编译流水线规划为 `Source → Token/CST/AST → HIR → MIR/LIR → Backend`。
- 核心安全模型采用所有权、借用与 RAII；可选 GC 只作为隔离实验。
- 首批目标覆盖 Windows、Linux、macOS，以及 x86_64、ARM64。
- 编译器、运行时、标准库和工具链保持单向依赖，实验能力不得阻塞稳定主线。

## 文档治理

- `README.md` 只维护项目简介、状态和入口，不复制详细规范。
- `docs/README.md` 是文档导航和归档规则的单一事实来源。
- 顶层母版负责范围与索引，详细规则应拆分到对应领域目录。
- 原始材料只提供历史证据，不能覆盖已批准的规范、RFC 或 ADR。
- 重大语言设计使用 RFC；重大工程决策使用 ADR，并保留被替代决策的历史。
- 新文档必须注明状态、负责人或责任角色、上游依据以及相关需求 ID。
- 同一事实只保留一个权威来源，其他文件通过链接引用。

详细规则参见[文档中心的维护约定](docs/README.md#文档维护规则)。
